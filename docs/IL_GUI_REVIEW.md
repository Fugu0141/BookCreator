# BookCreator — IL GUI連携


## IL品質診断・改善案の試算（IL-GUI-01）

全冊の配置案を反映した最新の実測紙面から、IL #131 の retained 診断を明示操作で取得する。全ページ数、空白、警告、希望位置のフォールバック、原稿別範囲を表示。共有ページを含む原稿は単独選択不可とする。改善目的と範囲をユーザーが指定したときだけ #130 の prepare API を使用し、改善指標または拒否理由を表示、レビューhandleは直ちに取消する。紙面・原稿・配置設定・履歴・印刷チケットを変更しない。実測候補比較・採用・永続化は後続段階。長冊試験に診断・明示範囲・試算後不変を追加。CI未確認。
