# BookCreator — IL GUI連携


## IL品質診断・改善案の試算（IL-GUI-01）

全冊の配置案を反映した最新の実測紙面から、IL #131 の retained 診断を明示操作で取得する。全ページ数、空白、警告、希望位置のフォールバック、原稿別範囲を表示。共有ページを含む原稿は単独選択不可とする。改善目的と範囲をユーザーが指定したときだけ #130 の prepare API を使用し、改善指標または拒否理由を表示、レビューhandleは直ちに取消する。紙面・原稿・配置設定・履歴・印刷チケットを変更しない。実測候補比較・採用・永続化は後続段階。長冊試験に診断・明示範囲・試算後不変を追加。CI未確認。

## IL-GUI-02：実測候補比較

CIが固定参照していたEngineのSHAを#132統合済みの796ba9e3c7a967590e8de3394062099b917d2eddに4ワークフロー共通で更新。原稿単位は#132の原稿ID APIを使用し、内部の排他的範囲で検証する。改善案を元retained snapshotから別の完全な候補DOMとして計測し、同一lease・元snapshot・候補snapshotをconfirm APIで検証する。confirmはエンジン上の一致確認であり、ユーザー採用や保存ではない。計測は共通レーンと協調チェックポイントを使用し、元キャッシュを共有せず、取消・範囲変更・画面終了で破棄。候補DOMにのみ変更断片の枠を追加し、原稿ID・部品ID・unit範囲の一致とDOM部品数を検証する。通常紙面を変更せず、候補の別枠表示と非表示を切り替える。印刷チケット・履歴・永続化は変更しない。長冊試験で候補が成立した場合の表示・強調・切替・取消を検査し、拒否の場合も元紙面・原稿不変を検査する。成立するケースの強制生成は後続。CI・実機未確認。
