# BookCreator — 画面・操作詳細設計

状態: ドラフト。基本要件F01〜F09を画面とコマンドへ対応づける。React共通UI。プラットフォーム固有操作はPlatform interface経由。

## 1. 全体

Project Manager（新規、開く、最近、複製、clone、import）→Workspace。未保存/未適用案がある状態の終了・プロジェクト切替は確認。Workspaceは上部モード切替、左セクション/素材/レイヤー、中央エディタ、右インスペクタ、下部保存・組版・Git状態。パネル折りたたみ、キーボード操作、フォーカス、ズーム。モード切替で原稿を正規化しない。共通コマンドは保存、Undo/Redo、検索、診断ジャンプ。ダイアログは危険な破壊的操作・適用確認に限定。

| モード | 中央 | 右側 | 保存対象 |
| --- | --- | --- | --- |
| Writing | ソース/構造GUI/分割表示 | 選択ノード属性 | 原稿・素材 |
| Design | Component/Page/Spread/Stress | Appearance/Structure/Pagination | テーマ作業案、Apply時のみ正本 |
| Layout | ページと境界・分割理由 | 個別改ページ/幅/余白等 | 明示原稿属性 |
| Publication | 全体HTML・サムネイル・見開き | 番号区間・プロファイル・検査 | manifest、ローカル確定記録 |
| Cover | 単独ページ/固定Canvas | 画像・配置・レイヤー | 表紙宣言/manifest |
| Source Control | 差分、stage、branch、history | Commit/Push/PR操作 | Git作業ツリー/履歴 |

## 2. 操作契約

Writing: GUIで既知要素のみ編集、未知/不正部分は原文表示とソースへの誘導。改ページマーカーはGUIでは既定非表示、表示切替で原稿を変更しない。画像選択時幅/高さ/比率/寄せ/クロップ/alt/caption。変更は局所パッチ。ソースとGUIの選択同期はrevisionで検証。章ツリーのファイルと意味的な見出し階層を分ける。

Design: レイヤー選択、追加/削除/複製/グループ/整列/スナップ/ロック、フロー順序とCanvas座標の操作を区別。実原稿は読み取り専用文脈。Apply/Discard/Continue editing、未適用案を保存で暗黙適用しない。局所プレビューを先に表示し、全体影響は別ジョブ。古い結果/仮番号を明示。

Layout: 原稿ブロックとページ断片の対応を利用。自動境界は灰色破線、明示境界はアクセント付き破線、表示ガイドは非出力。候補は一時案、Applyで明示指示を原稿に追加。自動分割が段落中なら安全なブロック境界を提案。前後の明示マーカーの移動/削除は選択確認。古い/部分計画からの不正な適用を拒否。表紙の表示切替で内頁面は変えない。

Publication: 単ページ/見開き、表紙単独、内頁の面に従う組合せ、欠け面プレースホルダーと実空白を区別。電子/両面印刷を選択、出力計画を表示。最新全体組版→Preflight→警告確認→Finalize→Export。PDF生成をFinalize前に要求しない。試し出力と正式出力を区別。入力変更で確定解除を非モーダル表示。

Source Control: 保存済みの差分と未保存バッファを区別。Pull/branch/merge前に確認。競合解決と参照再検査。秘密情報を表示・記録しない。

## 3. 実装単位

初期開発版のUIはProject Manager、Writingのソース編集、画像挿入、基本テーマとレイアウト、HTML確認/PDF出力をまず通す。構造GUI/フル部品エディタを初期公開にどこまで含めるかは公開ゲートで確認する。全製品要件を減らす意味ではない。各操作にloading/取消/エラー/無効理由を定義し、古い結果を最新として表示しない。UI-01〜08: 新規/切替、IME、画像、作業案、マーカー、見開き、確定、Git導線を受入検査する。
