# PAPER-GUI-03: 個別ブロックの占有領域操作（接続準備）

既存部品デザインの widthPercent は実測内容幅、minHeightPercent は最小高さ。登録部品の定義を編集すると複数の使用箇所に影響するため、執筆紙面の個別操作とは分離する。

LayoutEngine IL-04/06 の契約に合わせ、個別占有率は placement.sizeConstraints.minWidthPercent / minHeightPercent として生成する。0 は制約解除であり、Engineには送らない。占有率は本文矩形の軸ごとの割合。文字の折り返し・描画サイズ変更は別の再計測操作。固定配置には占有ドラッグを適用せず、固定解除も暗黙に行わない。競合はEngineの診断として扱う。

paper-area-intent.mjs は選択中の documentId / blockKey / revision / fingerprint / 単一断片を照合し、既存の位置・余白・他の寸法制約を保ったまま、新しい個別配置意図の候補を返す。入力を変更しない。ドラッグ中はCSSピクセルの仮ガイド用サイズを返し、ポインター確定だけで候補を生成する。取消・微小移動・元の位置への復帰・古い計画は無操作。既存 areaPercentFromDrag を共用する。

このPRは独立したGUI側の純粋計算モジュールと試験に限定する。画面にはまだ接続しない。現在の blockKey は永続IDとは限らないため、候補を保存ファイルに直接書き込まない。永続ID対応・意図スキーマ・Undo/Redo・Engine再計測/描画・PDFとの整合性が検証できるまでは操作ハンドルを有効化しない。通常の紙面・部品定義・PDF経路は変更なし。ILリポジトリへの変更なし。


## 個別指定の保存形式・編集トランザクション（接続準備）

現在の semantic blockKey は原稿開始オフセットであるため、保存キーとして使用しない。schemaVersion:1 と entries の厳密な JSON データ形式を追加。各 entry は documentId、persistentId、minWidthPercent / minHeightPercent のいずれか以上。0 は解除操作であり保存しない。派生座標、revision、fingerprint、測定サイズは含めない。原稿に永続IDのないブロックは対象外。保存候補ファイル名は layouts/paper-area.json とし、既存プロジェクト形式への登録、原子的なディスクI/O・外部変更検出、復旧処理は後続で確定する。

全対象範囲の最新計測断片から永続IDを現在の blockKey へ再解決する。欠落・重複・複数断片・現行キー衝突では全提案を拒否し、保存済み意図は消さない。別原稿の同じ永続IDは独立。旧原稿のオフセットによる補完は禁止。

draft は一操作一履歴、最大100件、Undo/Redo、新しい編集でRedo破棄、dirty状態、単調増加する編集版を持つ。controller は最新の成功計画、revision/fingerprint、永続ID、編集版を照合し、ドラッグ中は仮表示だけ、確定時に一回更新する。他の位置・余白・寸法制約は baseIntents から結合し、占有率の二重正本は診断する。ILの出力 placement を入力指定に流用しない。候補生成は組版成功やディスク保存を意味しない。

この段階でJSONの検証・直列化/復元、編集履歴、ドラッグ接続コントローラー、単体試験まで実装。実際の画面ハンドル、ディスク書込、IL計測/描画、原稿Undoとの統合、PDF出力ゲートは未接続。最新CI未確認。


## IL-09A 接続試験画面

執筆紙面で永続IDを持つ単一断片を選択すると「占有領域（試験）」を開ける。選択中の最新原稿だけを既存物理計測レーン経由で IL の createPlainTextPagePreview(options.intelligentLayout) に渡し、独立したDOMで結果を描画する。IL-09A/09B統合済み Engine commit 5ed44c9afeeb0f3923aa3aef89b23148307d8959 へ4 CIのpinを更新。通常の紙面、保存・試しPDF経路は変更しない。

内容枠とは別の占有枠の右端・下端をドラッグし、仮ガイドはCSSだけで更新する。確定時に一回の編集履歴と再配置要求、矢印キー・自動復帰・Undo/Redoも操作可能。競合時は前回成功紙面を維持し、診断を出す。古い原稿・閉じた画面への結果反映を拒否。閉じると試験案を破棄することを画面に明示。実マウスで縦占有率を変えるパッケージ試験を追加。

制限: この試験画面では永続化、原稿の履歴との統合、実測内容幅の変更、正式な書籍全体の配置/PDFは未接続。ILの占有率は最小の領域指定であって文字の縮小指定ではない。最新CI・実機動作は未確認。


## 試験配置案の保存・再読込

layouts/paper-area.json を試験配置案の保存先として採用。原稿単位に編集・再読込し、他原稿の指定を保持する。固定パス、シンボリックリンク・ハードリンク拒否、最大サイズ、形式検証、原稿と配置ファイルのrevision照合、一時ファイル同期と原子的置換を実装。初回作成は既存ファイルを上書きしない。IPCは現在の書籍セッショントークンを要求し、Windows配布にも必要ファイルを同梱する。

GUIはILが成功した最新編集版に限って明示的な保存を許可。未保存原稿からは保存せず、原稿保存後に紙面を開き直す。配置案の保存と原稿保存は独立。未保存案を閉じると破棄し、保存済み案を次回読込。既存原稿・通常プレビュー・PDFは変更しない。保存先はまだ出版用の正式manifest設定ではない。未知形式・外部変更では書換を拒否し、再読込を促す。現在の描画対象と永続IDの一致はGUI/ILで検証する。外部編集との完全な相互排他、欠落IDの明示修復、正式出版への反映、GUI保存往復のパッケージ実測は後続。

実ファイルを使う単体試験で初回保存、再オープン、他原稿保持、解除、外部変更、リンク、未知形式を確認する。最新CIの成功は未確認。


## 通常紙面への保存済み配置案の反映

執筆・全冊組版の紙面に「保存済み配置案を反映（試験・PDF不可）」を追加。既定OFF、書籍切替でOFFへ戻る。明示ON時のみ、最新の配置ファイル全体を既存のプレビュー読込レーンと書籍トークン経由で取得する。選択原稿ではその原稿の指定だけ、全冊では全指定を対象とする。準備済みブロックの永続IDから現行blockKeyに対応付け、既存計測＋ILへ渡す。欠落・重複・複数断片・制約競合では結果を採用しない。IL結果のrevision/fingerprint・実際の断片ID・最小占有矩形を検証後にのみ公開する。旧版の紙面は新しいモードの紙面として再利用しない。OFF時の既存組版と性能経路は維持する。

ON時は安全のため全描画を使用（増分・部分再利用は後続）。試験案を編集後に閉じると再組版を要求する。ILの試しPDF計画一致ゲートを本体の印刷IPCへ接続するまで、ON時は試し出力を無効にし、main側でもILオプションを含む旧形式のPDF要求を拒否する。OFF時の既存PDFは試験案を含まない従来経路。正式出版は未対応。

準備/検証の単体試験と、保存ファイルfixtureによる通常紙面の後続ブロック位置変更・OFF復帰のWindows実マウス既存試験への追加を実装。ブラウザCIのRUNNING終了に対し試験段階マーカーと仮想時間予算を追加（原因確定・成功は未確認）。通常紙面でのインラインリサイズとPDF計画一致の接続は次段階。


## 通常紙面の直接リサイズ（試験）

保存済み配置案反映ON、原稿・テーマ・書籍設定が保存済み、最新の単一断片・永続IDが確定した場合に限り、既存移動枠の右端と下端に直接リサイズハンドルを表示する。操作中はCSSの枠と割合だけを更新。ドロップ時は未確定の提案を表示し、明示的な「適用して保存」で独立した計測レーン上のIL計画を検証し、原稿・設定の版を確認して保存する。その後通常紙面を再組版する。0%（自動復帰）、Esc、矢印キーをサポート。未確定の提案は選択変更・画面変更で破棄される。固定配置、旧revision、保存競合、分割や欠落で確定しない。印刷DOMへハンドルを挿入しない。

保存は明示的に行うため、通常紙面のドラッグ直後はガイドまで。確定前に実際の後続ブロックを再配置する機能、保存済み指定の直接操作履歴、全冊の直接操作、IL PDF一致ゲートは後続。最新CI・実マウス検証は未確認。#249の全CI成功・main統合を反映し、移動操作・試験を保持した。


## 通常紙面の保存済み配置履歴（試験）

紙面編集モードで保存済み配置反映をONにした場合、「配置を元に戻す」「配置をやり直す」を使用できる。原稿本文の履歴とは独立。横・縦をまとめた一度の保存が一履歴単位で、復元案も通常の保存と同じIL計測・検証・原稿revision・保存ファイルrevisionの確認を経て確定する。未確定案や失敗した保存は履歴に含めない。書籍を開き直すと履歴を破棄する。原稿・テーマ・書籍設定または保存ファイルの版が一致しない場合は履歴操作不可。履歴は最大100件のセッション内記録であり、再起動後の復元・全冊の直接操作・PDF一致・ドラッグ中の実測再配置は未対応。

## 部品の後ろの余白（試験）

通常紙面の選択ブロックに「後ろの余白」スライダー（1mm刻み）を追加する。0は指定解除。横・縦の最小占有率とは独立したILのspaceAfter（整数µm）を永続ID付き配置データへ保存し、確定前の実測・履歴・競合確認を同じ経路で行う。色付き点線は後方余白の目安で、実測結果が予約領域を満たさない場合は保存しない。試験GUIは既存の余白を維持し、占有率の高さから余白を除外する。従来のschemaVersion 1文書は引き続き読めるが、新しいspaceAfter付き文書を旧アプリで開くことはできない。余白の専用ドラッグハンドル・前方余白・分割ブロック対応は後続。


### 後方余白の直接ドラッグ

青い縦横ハンドルとは独立した橙色の「↕」ハンドルを後方余白の終端に表示する（0mmからも開始可能）。上下ドラッグ・矢印キーで1mm刻み、Shift＋矢印で5mm刻み。原稿の本文高さと画面拡大率から物理単位へ変換し、0まで戻せる。操作中は未確定ガイド・実測プレビューのみ。Esc、ポインター取消、対象変更でジェスチャを破棄し、確定ボタンのみ保存する。余白の終端が画面外の場合はスライダーを利用する。実機操作の確認は後続。


### 前方余白と前後の一括調整

spaceBeforeをspaceAfter・横縦占有率と独立して1mm刻みで指定できる。前後のスライダーは同じ操作欄に並べ、適用時は単一の履歴・保存処理とする。前方余白はIL計測結果の同一ページ先行占有領域の下端（先行部品がなければ本文上端）との物理距離を検証する。新しいページに移った場合も余白を維持する。前方の点線は暫定ガイドであり、実際の移動は実測プレビューによる。前方専用のドラッグハンドルは未対応。新しいspaceBefore付き設定は旧アプリでは読めない。
