# 実用化フェーズ（2026-11-28）

利用者の指示により、#232 の統合を区切りとして個別の性能最適化より制作工程の実用性を優先する。既存のリアルタイム組版・データ保全・ライブラリ分離を維持し、性能修正は実際の制作で支障が観測された箇所を優先する。DESIGN、Q15、PDF_EXPORT の公開・出版ゲートは緩和しない。

## 実用化の順序（暫定）

| ID | 制作工程 | 受入条件 |
| --- | --- | --- |
| PRACTICAL-01 | 新規書籍 | 白紙と編集可能な数学参考書のひな型を選択し、複数原稿を保存・再読込できる。既存フォルダを上書きしない。 |
| PRACTICAL-02 | 執筆と構成 | 実際の参考書を章単位で編集し、見出し・数式・例題・練習問題・解説をGUIで挿入・修正・移動できる。原稿の内容を失わない。 |
| PRACTICAL-03 | 図表・脚注・参照 | 既存の対応状況を確認し、不足機能を追加。実紙面と番号・参照の整合を検査。 |
| PRACTICAL-04 | 書籍デザインと全冊組版 | 部品・余白・ページ順・改ページ・目次・ノンブルを確認し、欠落や重複を検査。未対応は明示。 |
| PRACTICAL-05 | 試し出力・出版 | PDF_EXPORT の契約に従い、全冊試しPDFと安全な保存を先に整備。正式出版は別ゲート。 |
| PRACTICAL-06 | Windows実用評価 | 日本語IME、DPI、保存・復旧、長い原稿、出力を実機で確認。実測に基づく不具合のみを優先して修正。 |

PRACTICAL-01: 新規作成フォームに白紙（既定）と数学参考書（編集可能なサンプル）を追加する。後者は使い方、一次方程式の解説、練習問題の3原稿を生成し、数式・例題・問題/解説の参照を含む。外部ファイルや素材を取得せず、既存のプロジェクト生成・manifestの最後の書込みを利用する。正式なテンプレート管理や既存プロジェクトへの適用は対象外。

検証: 新規作成・保存・再読込・不正テンプレート拒否の単体テストを追加。Desktop smoke に新規作成画面→3原稿→構造化編集→保存→全冊実測組版→ホームから再開→再組版の通し検査を追加。数式と複数原稿の紙面反映・他原稿とmanifestのバイト不変も検査する。既存Windows配布版の再起動検査とは分離した。最新headのCI、Windows実機は未確認。合格とみなさない。
