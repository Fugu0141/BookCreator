# BookCreator — ホーム / 書籍プロジェクト管理（UX-02c）

状態: 実装・検証中。BC-UI-R2 のホーム設計を利用者レビューに基づいて具体化。参考は提示された Word の起動画面（新規・テンプレート・最近の文書）と Unity Hub（プロジェクト一覧・検索・追加・新規作成）。製品ロゴや個人のファイル名・パスのコピーは行わない。

    ┌ BookCreator ─────────────────────────────────────────────────┐
    │ プロジェクト │ 書籍プロジェクト                ＋ 新しい書籍 │
    │ 新規書籍     │ 検索 [             ]  お気に入り  並び順     │
    │ 開く         ├────────────────────────────────────────────────┤
    │              │ 名前 / 保存場所          最終アクセス    操作 │
    │              │ 数学参考書                今日           ☆ … │
    │              │ 物理教材                  昨日           ★ … │
    │ 編集に戻る   │                                                │
    └──────────────┴────────────────────────────────────────────────┘

- 起動時はプロジェクト一覧。新規は別の作成面（白紙、将来はテンプレート）、既存はファイルピッカー。開くとWorkspaceへ移動し、ホームでは工程ナビ・原稿保存・部品編集を表示しない。同一書籍のホームへの移動は編集中バッファを保持。
- 開いた/作成した書籍を利用者のローカルuserDataに登録。書籍名、book.yamlの正規パス、最終アクセス日時、お気に入りを保存し、検索・名前順/最近開いた順で絞る。更新日時ではなく最終アクセスを明記。再起動後も表示。最大100件（お気に入りは自動削除しない）。
- 一覧の操作は「開く」「お気に入り」「登録解除」。登録解除で書籍本体や原稿を削除しない。ファイル移動・破損・権限不足時は既存の安全なopenWorkspace検証に従い、エラー表示と開き直し。自動スキャン・ネットワーク同期・OSファイル削除を行わない。
- IPCは登録済みIDで開く。rendererから任意パスを読み取る汎用APIを追加しない。カタログの破損時は無断上書きしない。保存失敗は書籍の作成/読込成功と分けて通知。
- 個別原稿の追加/改名/削除/移動は書籍内部の原稿管理（Writingのアウトラインまたは書籍設定）に残し、ホームの書籍一覧と混同しない。章作成等は安全なファイルトランザクションを実装後に開放。
- テンプレート一覧、プレビュー、保存先の再指定、移動した書籍の再関連付け、アプリ設定は後続。未対応のボタンを表示しない。
- UX-02cではローカル登録・一覧・作成・開く・お気に入り・検索・登録解除の基盤を優先。CIの登録ID、永続化、原文不変、Windows再開操作の確認後、利用者の実機レビュー。見た目の配色/寸法は暫定。CI未確認。親PR #69/#70 のマージ後にmainへ。
