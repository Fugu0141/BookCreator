# 構造GUI編集の実用化判定（UX-08f）

2026-11-26 / 対象: Windows Desktop 試作版

## 判定

ソース編集を既定のまま維持する。構造編集は選択可能な試作機能として提供する。GUIの既定化は既存の執筆能力を維持し、原稿の安全な往復と実作業を確認してから行う。CI成功と実機評価を区別する。

## 機能照合

| 機能 | 構造編集 | ソース編集・既存導線 | 既定化前の対応 |
|---|---|---|---|
| 見出し・本文 | H1–H6、対応する複数行段落 | 原稿編集 | 空行分割・結合、選択範囲、IME |
| 文字書式 | 太字・斜体・下線、解析済みの表示 | 書式、色、サイズ、フォント、上下付き等 | 記法を意識しない編集、既存書式の解除・変更 |
| リスト | 独立リストの項目編集・変換・2階層、単一階層の追加/削除（今回） | リスト変換、階層操作 | 複雑な階層、Enter/Tab操作、実機検証 |
| 数式 | 独立・本文内の表示/編集、テンプレート、トップレベル採番・参照挿入 | 挿入、番号付き、参照、部品内の意味的編集 | 教材部品内採番・参照、参照付き文章の再編集・挿入 |
| 教材部品 | 標準/登録部品の挿入、既存欄の内容編集、必須/任意欄、ID生成・解答先選択 | ID・解答先指定、登録部品、名前付き欄 | 関連付けの回帰・実機検証、欄の追加/削除 |
| ブロック操作 | 安全な境界挿入、本文/番号なし式の移動/複製/削除 | 任意のソース範囲 | 章・採番・参照への影響検査、対象拡充 |
| 履歴 | 構造編集の最大20操作 | テキスト入力履歴 | モード横断の方針、保存前後と原稿切替 |
| ソースとの往復 | 同一の未保存原稿、対象範囲ジャンプ | 原文維持 | 複雑な原稿、改行・大容量、エラー時の試験 |
| 紙面 | 別トグル、組版は既存経路 | 選択原稿/全冊組版 | GUIからの原稿位置との連携 |
| 正式出版 | 未実装 | 試作組版・既存試し出力基盤 | UX-08とは別の正式出版要件 |

## 検証ゲート

1. 既存5CIすべて成功、既存回帰を削除しない。
2. 新規書籍で見出し・本文・数式・自作教材部品を挿入、名前付き入力欄を編集、保存・再開、全冊組版を一連の操作として確認。
3. 既存原稿の非対応部分を失わずソースで編集可能。モード切替、未保存確認、取消、IME、外部変更、Undo/Redoの試験。
4. 数式番号、参照、解答リンク、章順への影響を検証。未対応操作は明示する。
5. Windows実機で狭幅・表示スケール・キーボード・日本語入力・視認性を確認。

今回のPRは登録部品の挿入と既存欄構成の連携を追加する段階。CI・実機結果は別途記録する。見た目が完全な組版結果になること、全機能のGUI同等性、正式PDF出力はまだ保証しない。
