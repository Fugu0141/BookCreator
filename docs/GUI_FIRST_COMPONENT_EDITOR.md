# GUI-first 部品エディタ再設計（2026-11-28）

利用者の要望: Canvaのような直接操作型GUIを標準とし、数値入力を精密調整用のオプションにする。スクリーンショットでは見出しの中央に実測紙面がある一方、操作の主役は左の構造・ライブラリと右の数値プロパティになっている。既存の自動計測、undo/redo、ロック、復旧、部品定義と組版Engineの分離は維持する。

## 操作設計

- 中央: 部品を必要な大きさで表示するキャンバス。クリックで選択、ドラッグで移動、ハンドルで幅/高さ変更、ダブルクリックで固定文字編集。選択した要素の近くに操作を表示。実際の本文スロットの文字列は部品の固定文字に変換しない。
- 上: 選択対象に応じたツールバー（文字のフォント・色・サイズ、図形色、整列・重ね順）。文字サイズは視覚的な選択/増減、余白・間隔はドラッグとスライダーを基本とする。
- 左: 要素追加と折りたたみ可能なレイヤー。ライブラリは別タブ/開閉式にする。通常の操作に全レイヤーの数値編集を要求しない。
- 右: 選択要素の簡易編集と必要時に開く「精密調整」。X/Y/W/H、文字サイズ、余白の正確なmm値などは既定では非表示。現在の数値単位・保存スキーマは維持。
- 右クリックやキーボードでも複製、削除、移動、整列、元に戻す。ロックと内容保護は全入口に適用する。
- 再計測は通常操作に不要。自動表示を既定にし、再試行はエラー時または詳細操作へ移す。

## 組版と直接操作の両立

書籍の見出し、例題、練習問題では本文量が変わる。行/列の自動配置を既定に維持し、要素のドラッグ並べ替え、間隔・幅ハンドルで編集する。固定座標が必要な装飾は自由配置グループに隔離し、既存Canvasスキーマ・制約を使う。本文の長さに追従できない絶対配置をすべての部品に強制しない。装飾の自由配置と本文スロットの伸縮を区別する。

ドラッグ中はブラウザの変形/ハンドル表示で即時応答し、確定時に一回の履歴操作として保存案に反映して実測を更新する。文字の折り返しや高さはEngineの結果を使用し、別の組版実装や疑似の正式紙面は作らない。最新計測以外で適用・登録できない条件を維持する。

## 実装順

| ID | 受入条件 |
| --- | --- |
| GUI-01 | 行・列・自由配置の要素がキャンバスから選択でき、レイヤー/プロパティ/選択枠が同期。マウスとキーボードで操作。 |
| GUI-02 | 横/縦並びでドラッグによる並べ替え、幅・余白・間隔の視覚的操作。自由配置は既存のドラッグ/吸着を継承。 |
| GUI-03 | 選択に応じたツールバー、固定文字の直接編集、サイズ・色の簡易操作。数値入力は精密調整へ移す。 |
| GUI-04 | キャンバス中心の画面、折りたたみ可能なレイヤー/ライブラリ、再計測の補助操作化。 |
| GUI-05 | 見出し・本文・例題/練習問題・独自部品で同じ操作体系を確認。Windowsマウス/キーボード、DPI、長い可変原稿、undo/redo・復旧・実PDF確認。 |

GUI-01の初段階では既存の実測DOMを選択対象に広げる。非自由配置要素は選択のみで、自由配置への暗黙変換や数値UI削除は行わない。既存ドラッグ経路の回帰防止、原稿スロットと装飾の選択テストを追加。CIと実機は未確認。GUI-02以降で操作系と画面を順次入れ替える。
